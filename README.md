# Website Designer

Самостоятельный агент, который ведёт пользователя от идеи до полного адаптивного сайта. Подходит для Codex и Claude Code; установка скиллов исходной студии не требуется.

## Как работает

1. Собирает вводные и анализирует конкурентов
2. Готовит тексты через субагента-копирайтера, если делегация доступна
3. Показывает три сайта-референса или разбирает ваши примеры и объясняет, что адаптирует
4. После вашего «делаем» или «продолжай» самостоятельно создаёт весь согласованный сайт
5. Проверяет desktop, mobile и основные действия, затем вносит правки

Тексты впервые показываются в самом сайте. Обязательных промежуточных выборов композиций, палитр, шрифтов и двух концептов нет. Правила композиции, типографики, изображений и защиты от нейрослопа включены в пакет.

## Быстрый старт

Скачайте или клонируйте этот репозиторий в отдельную рабочую папку. Откройте её в Codex либо запустите из неё Claude Code и напишите:

> Помоги создать сайт для … Проведи меня по этапам по инструкции этого проекта

Codex использует `AGENTS.md`; `CLAUDE.md` импортирует ту же инструкцию для Claude Code. Для нового клиента используйте отдельную копию проекта. Если пакет добавлен в уже открытую сессию, попросите сначала прочитать `AGENTS.md`.

Поиск, визуальный браузер, генерация изображений, субагенты и публикация зависят от инструментов вашей среды. Агент сообщает ограничения и не выдаёт непроведённые проверки за выполненные. Полноценное создание сайта в обоих приложениях отдельно не тестировалось.

Подробности запуска, состав пакета и источники: [START.md](START.md).
