# Самостоятельный агент Website Designer

Пакет можно передавать другим пользователям целиком. Он содержит ведущего агента, правила дизайна, анализа референсов, текстов, SEO/GEO и изображений, задания копирайтеру и SEO/GEO-субагенту, а также справочник по SEO/GEO. Исходная студия, установленные скиллы и материалы клиентов не нужны. Это инструкции для работающего Codex/Claude Code, а не отдельная программа с собственными инструментами.

## Запуск

1. Распакуйте пакет в отдельную новую рабочую папку вне каталога нашей студии. Для каждого клиента используйте свою копию папки. Не заменяйте существующие инструкции чужого проекта без осознанного объединения
2. Откройте папку `website-designer`, непосредственно содержащую `AGENTS.md`, как проект в Codex или запустите Claude Code из неё. Сохраните `AGENTS.md`, `CLAUDE.md`, `rules/` и `prompts/` вместе
3. Напишите: «Помоги создать сайт для … Проведи меня по этапам по инструкции этого проекта». Если подключаете пакет в уже открытой сессии, явно попросите сначала прочитать `AGENTS.md`

Для рабочего сайта понадобятся Node.js на компьютере и бесплатные аккаунты Supabase, Vercel и Telegram; агент проведёт по шагам, когда до них дойдёт очередь.

Агент соберёт вводные, изучит конкурентов и параллельно подготовит SEO/GEO-основу, подготовит текст внутри проекта и покажет три референса с конкретным планом адаптации. После вашего «делаем» или «продолжай» он самостоятельно создаст полный адаптивный сайт, покажет текст уже в дизайне и выполнит доступные проверки. Промежуточных обязательных выборов композиций, цветов и шрифтов нет.

Можно дать свои референсы, разрешить агенту предложить концепцию при нехватке сведений или прямо поручить ему весь выбор. Реальные отзывы, цены и свойства бизнеса он не должен придумывать. Для генерации изображений, визуального браузера, субагентов и публикации нужны соответствующие инструменты/доступы в вашей среде. При их отсутствии агент сообщает ограничения и использует доступный способ работы.

## Файлы

- `AGENTS.md` — основная инструкция ведущего агента
- `CLAUDE.md` — импорт той же инструкции для Claude Code
- `rules/DESIGN.md` — арт-дирекшн, композиция, типографика, изображения, движение и защита от нейрослопа
- `rules/REFERENCES.md` — анализ конкурентов и адаптация визуальных ориентиров
- `rules/COPYWRITING.md` — смысл, достоверность и интерфейсные тексты
- `rules/SEO_GEO.md` — видимость в Яндексе, Google и ИИ-ассистентах: запросы, структура, метаданные, JSON-LD, служебные файлы, чек-лист после запуска
- `rules/STACK.md` — стек по умолчанию (Next.js + TypeScript), где лежит код, секреты, публикация на Vercel
- `rules/LEADS.md` — рабочая форма заявок: серверный обработчик, Supabase, уведомления в Telegram, проверка
- `rules/IMAGES.md` — откуда брать изображения (генерация в Codex, промпты для пользователя в Claude Code, фотобанки) и как готовить их для сайта
- `prompts/COPYWRITER.md` — задание субагенту-копирайтеру
- `prompts/SEO_GEO.md` — задание субагенту SEO/GEO
- `library/marketingskills/` — справочник: скиллы `ai-seo`, `schema`, `seo-audit` без изменений, лицензия MIT

## Происхождение и совместимость

Правила адаптированы из общих `DESIGN_RULES`, `REFERENCE_RULES`, `COPY_RULES`, `LEARNED_RULES` и навыков `website-competitor-analysis`, `website-copywriting`, `hero-art-direction` исходной студии. Они включены в этот пакет, а не подключаются по внешним путям. Клиентские материалы и прежний процесс выбора двух концептов не включены. Скиллы `ai-seo`, `schema` и `seo-audit` взяты из [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) (коммит `365b412`, лицензия MIT) и лежат вне папок автозагрузки скиллов, чтобы не запускать аудит существующего сайта сами по себе; порядок работы с ними задают `rules/SEO_GEO.md` и `prompts/SEO_GEO.md`. Изменения этого пакета не меняют основной процесс студии.

Для Codex используется проектный `AGENTS.md` согласно [официальной документации OpenAI](https://learn.chatgpt.com/docs/agent-configuration/agents-md). Для Claude Code `CLAUDE.md` содержит `@AGENTS.md` — поддерживаемый [импорт общей инструкции](https://code.claude.com/docs/en/memory#share-one-file-with-other-coding-tools). Полноценный запуск обоих приложений и создание сайта в них этим пакетом отдельно не проверялись; проверены структура, переносимость файлов и сценарии поведения инструкции.
